=== Декомпозиция ===

Пишем код для игровой логики на C#. Строго иользуем принципы SOLID, Clean Code, TDD. Но сильно не перегружаем, простота кода тоже приветствуется. Игра содержит:

- Акт - номер акта, название акта. Колоду карт акта

- Карта локации - номер акта, название локации, описание события при попадании на локацию
- Событие при попадании на локацию, может быть обязательным для выполнения, обязательным с условием выполнения или провала либо не обязательным для выполнения
