# Diablo: Desperate Gods — Источники данных и ресурсы

## Что это

Diablo-версия настольной игры **Desperate Gods** (Wolfire Games) — цифровой паттерн-кроллинг
на Unity. Игроки перемещаются по доске 9×7, сражаются с монстрами за кубики, собирают
снаряжение и золото, копят победные очки.

## Источники

Папка organizована по legacy-проектам:

```
src/Diablo/
├── DesperateGodsDiablo/     ← Unity-проект (Desperate-Gods-Diablo)
├── DiabloTTS/               ← Tabletop Simulator-моды (Diablo Desperates Gods)
└── DesperateGodsFiles/      ← Сборник скриншотов и правил (Desperate-Gods-Diablo-Files)
```

## Данные игры

### `DesperateGodsDiablo/Data/cards.json`

Все колоды карт в JSON-формате:

| Колода | Карт | Описание |
|--------|------|----------|
| Wilderness | 7 | Монстры дикой местности (Target 2–3) |
| Dungeon Lvl 1 | 7 | Монстры первого уровня (Target 3–5) |
| Dungeon Lvl 2 | 7 | Монстры второго уровня (Target 4–5, локации) |
| Dungeon Lvl 3 | 6 | Монстры третьего уровня (Target 5–6, события) |
| Gear | 13 | Снаряжение (оружие, зелья, свитки, ботинки) |

**Схема карты монстра:**
```json
{
  "Title": "Название",
  "Type": "Тип (строка, не enum)",
  "Target": 4,        // значение кубика для победы
  "Gold": 2,          // награда за победу
  "Points": 3,        // победные очки
  "Rules": "Текст",   // специальное правило
  "Flavour": "",      // лор-текст
  "Duplicates": 1     // количество копий в колоде
}
```

**Схема карты снаряжения:**
```json
{
  "Title": "Название",
  "Price": 5,         // стоимость в золоте
  "Rules": "Текст",   // эффект предмета
  "Duplicates": 2     // количество копий
}
```

Доска 9×7 с 44 клетками, 4 цветовые зоны:

| Зона | Цвет RGB | Клеток | Описание |
|------|----------|--------|----------|
| Wilderness | [90,143,89] | 13 | Дикая местность, Торговля |
| Dungeon L1 | [101,101,101] | 15 | Первый уровень подземелья |
| Dungeon L2 | [69,60,60] | 12 | Второй уровень, лабиринт |
| Dungeon L3 | [84,0,0] | 4 | Ад: Алтарь, Пентакл, Врата Ада, Тьма |

**Схема клетки:**
```json
{
  "Pos": [x, y],      // позиция на сетке
  "Title": "Название",
  "Rules": "Эффект",  // что происходит при попадании
  "Color": [r, g, b]  // цвет зоны
}
```

## Механики

- **Бой:** бросок кубика >= Target монстра. Победа = Gold + Points. Поражение = эффект Rules.
- **Золото:** покупка снаряжения в Town.
- **Победные очки:** накапливаются, определяют победителя.
- **Снаряжение:** одноразовые или ломающиеся предметы (бросок кубика при использовании).
- **Движение:** бросок кубика, перемещение по доске. Некоторые клетки перемещают принудительно.
- **Town:** heal damage, purchase equipment.

## Контент для TurnBased

Данные `cards.json` и `board.json` готовы к импорту в `ContentRegistry` ядра TurnBased:

```csharp
// Пример загрузки контента
var cards = JsonSerializer.Deserialize<CardsData>(File.ReadAllText("cards.json"));
foreach (var card in cards.Wilderness)
    content.Register(card.Title, card);
```

## Архитектурный референс (Unity-код)

Папка `DesperateGodsDiablo/Code/` содержит 10 ключевых скриптов Unity:

| Скрипт | Что делает | Ценность для TurnBased |
|--------|-----------|----------------------|
| `CardManagerScript.cs` | Загрузка карт из JSON, бейкинг текстур | Паттерн загрузки контента |
| `ObjectManagerScript.cs` | Управление всеми объектами, физика захвата | Паттерн менеджера/синглтона |
| `DeckScript.cs` | Колода: толщина по количеству карт, тасовка тряской | Модель колоды |
| `BoardCreateScript.cs` | Создание доски из данных | Паттерн билдера |
| `TileManagerScript.cs` | Бейкинг тайлов на текстуры | Паттерн рендеринга |
| `CardScript.cs` | Флип, захват, коллизия с колодами | Игровые события |
| `NetUIScript.cs` | Сетевой UI, чат, музыка | Паттерн UI-контроллера |
| `NetworkRigidbody.cs` | Синхронизация физики через RPC | Паттерн сетевой синхронизации |
| `CardData.cs` | DTO карты | Модель данных |
| `MiniJSON.cs` | Парсер JSON (встроенный) | Утилита |
